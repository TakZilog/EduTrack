# Enrollment map photos

Photos for the offices the enrollment map cannot already show through the
building walkthrough (`assets/nodes/`), because those offices are not on the
room graph yet: the Registrar's Office, the Admin Office, and the HRM
Facilitator's desk. Steps that map to a room already on the walkthrough
(Cashier, Property Custodian, Library, Technical Office, Room 107, Slab 1,
Faculty) use that room's own door photo instead and need nothing added here.

Drop a photo in with the exact file name below and it appears on the
enrollment map automatically, no code change needed. Any of `.jpg`, `.jpeg`,
`.webp`, or `.png` works; if the file is missing, that step shows a plain
office icon instead, so a missing photo is never a broken image.

| File name (any listed extension) | Step |
|---|---|
| `step-01-registrar` | Step 1 and Step 5, Registrar's Office |
| `step-03-hrm` | Step 3, HRM Facilitator |
| `step-06-admin` | Step 6 and Step 7, Admin Office |

Keep the photo close to what the walkthrough shoots: taken standing at the
office door, facing in, well lit, no people identifiable in frame.
